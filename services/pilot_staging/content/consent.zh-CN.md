# ResearchOps 外部科研用户 Pilot 参加前说明

本活动测试一个可能出错的科研数据分析 AI 原型，预计需要 40–50 分钟，并按固定顺序提供 6 个基于公开数据的任务。你只需判断回答是否易懂、是否有助于下一步，不需要判断统计、医学或领域结论是否专业正确。你可以跳过任一任务或随时退出；跳过或退出不影响已经说明的固定补偿，也不会触发该题重跑。

参加前请确认：

1. 你已满 18 岁并自愿参加；
2. 你知道结果不得直接用于临床、科研发表或其他实际决策；
3. 你只使用项目提供的公开数据，不输入个人、患者、机构或保密数据，也不输入 API Key；
4. 你知道页面中的题目及受控聚合信息会发送给明确披露的模型 Provider；
5. 你同意记录随机参与者 ID、任务状态、Provider 延迟、人工阅读时间、反馈和安全事件；
6. 姓名、邮箱、机构、IP、API Key、原始研究行、答案正文和自由文本备注不会进入公开证据；
7. 参与者级数据最多保留 90 天；你可以随时退出，退出会立即阻止后续模型调用，并在最多 7 天内处理参与者级删除；
8. 默认不录音、不录像；若未来需要，必须另行征得同意。

补偿安排（如有）会在邀请消息中提前披露；补偿不得取决于反馈是否正面。技术或隐私问题可通过项目的公开问题入口联系组织者：`https://github.com/cedRiC874/researchops-agent/issues`。请勿在公开问题中粘贴邀请令牌、任务答案、个人信息、研究数据或 API Key。

本轮冻结 Provider 为 DeepSeek，模型为 `deepseek-v4-flash`。只有页面中的预设公开任务和受控聚合数据会发送给该 Provider；参与者不提供 Provider 凭据。

如果本活动未来用于论文或旨在产生可推广的人类受试者研究结论，组织者应在招募前取得所属机构的伦理/IRB 判断；本页面不自行宣称豁免。
