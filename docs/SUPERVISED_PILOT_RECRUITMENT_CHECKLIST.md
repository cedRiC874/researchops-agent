# ResearchOps Agent Supervised Pilot 招募检查表

> 版本：`supervised-pilot-recruitment-v1`
> 规模：1–2 人
> 用途：正式外部 pilot 前的监督操作预试；不构成外部验证

## 1. 固定招募说明

向所有候选人使用相同说明：

> 我们正在对 ResearchOps Agent 的邀请、同意、页面操作和反馈流程进行一次 1–2 人监督预试。体验约 40–50 分钟，使用项目提供的公开数据完成 6 个任务。你只需评价页面与回答是否易懂、是否有助于下一步，不需要判断统计、医学或领域结论是否正确。本场不录音、不录像、不录屏，也不会要求你的 API Key 或自己的研究数据。你可以随时退出；补偿（如有）是预先固定的，不取决于完成题数、评价正负或是否发现问题。本阶段不是正式外部验证。

## 2. 招募前固定项

- [ ] 计划人数固定为 1–2 人，不因结果好坏追加人数。
- [ ] 每人任务数固定为 6，任务顺序由冻结 task pack 确定。
- [ ] 补偿形式与金额已固定：`[填写固定金额或固定礼品；无补偿则写“无”]`。
- [ ] 提前撤回的补偿规则已固定并写入邀请：`[填写规则]`。
- [ ] 补偿与正面评价、完成题数和发现问题数量均无关。
- [ ] 招募渠道为定向邀请；没有公开注册链接或可转发匿名链接。
- [ ] 联系/排期/支付表与 pilot 数据分离，并设置最小访问权限。
- [ ] 招募文案没有使用“专家验证”“准确率验证”“生产可用”等表述。
- [ ] 已确认是否需要机构 IRB/伦理判定；若需要，相关判定已取得。

## 3. 纳入资格

以下条件必须全部为 Yes：

- [ ] 已满 18 岁并能自主作出参与决定。
- [ ] 当前或近期从事科研、研究支持、研究数据或研究报告相关工作。
- [ ] 能够阅读当前 pilot 使用的界面语言。
- [ ] 未参与 ResearchOps Agent 的设计、实现、任务编写、评分或结果筛选。
- [ ] 不是项目作者的直接上级、下级、被考核者或其他可能受到不当压力的人员。
- [ ] 未查看隐藏 expected/golden 或其他参与者反馈。
- [ ] 理解本阶段只评价可用性，不承担专业正确性判断。
- [ ] 同意只使用项目提供的公开数据，不输入自己的研究、患者、机构或保密数据。
- [ ] 同意不提供 API Key，且知道 Provider 调用使用服务端凭据。
- [ ] 接受无录音、录像、录屏和自动转写的场次方式。
- [ ] 知道可以跳题或随时撤回，且补偿不以正面评价为条件。

任何一项为 No 或无法确认时，不纳入本次预试。

## 4. 排除条件

出现任一情况即排除，但不得在 pilot 分析记录中保存排除者姓名或邮箱：

- 未满 18 岁、不能自主同意或明确不同意；
- 项目作者、代码/文档贡献者、任务或 golden 编写者；
- 与项目作者存在可能导致不自愿参与的直接管理或考核关系；
- 已看过隐藏答案、machine score 或本轮其他参与者反馈；
- 希望上传个人、患者、机构、未公开或受许可限制的数据；
- 要求使用自己的 API Key 或任意 Provider endpoint；
- 参与目的为临床、科研发表或其他实际决策，而不是流程预试；
- 所在机构明确要求伦理审批但尚未取得所需判定；
- 无法接受数据最小化、无录音录像或撤回规则。

候选人是否是某个领域专家不是自动纳入或排除条件；即使具备专业背景，本阶段仍固定记录 `professional_correctness_assessed=false`。

## 5. 联系信息与假名分离

联系表只能包含招募和排期所需信息，并保存在 pilot 数据库和 Git 之外。建议字段仅为：联系方式、排期状态、补偿处理状态和随机 `participant_id` 的映射。任务、反馈、日志和单场记录只能使用随机假名 ID。

以下内容不得复制到 pilot session 或场次记录：

- 姓名、邮箱、电话、社交账号；
- 单位、实验室、精确职务；
- IP、设备标识或会议链接；
- 支付账号和凭证；
- API Key；
- 参与者自己的研究题目或数据。

排期和补偿处理完成后，按预先说明的期限删除联系映射；最长保留不能超过协议约定。

## 6. 邀请发送前最终确认

- [ ] 候选人资格已核验，但资格材料未写入任务记录。
- [ ] 使用一次性、短期有效的邀请，不含姓名或邮箱。
- [ ] 候选人收到固定补偿与撤回说明。
- [ ] 候选人知道本场不录制、不评专业正确性，也不是正式外部验证。
- [ ] 候选人知道禁止输入自己的数据、身份信息和 API Key。
- [ ] 主持人、场次记录模板和退出路径均已准备。

若预试材料未来用于论文、可推广研究结论或超出最小操作反馈，必须在招募前取得相应机构的 IRB/伦理审查或书面判定；本检查表不能证明或替代“豁免”资格。
